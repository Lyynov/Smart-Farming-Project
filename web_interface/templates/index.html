Smart Farming System

Monitoring dan kontrol pertanian yang efisien dengan teknologi WSN, Computer Vision, dan Fuzzy Logic.

Dashboard Pelajari

Fitur Sistem

Monitoring Kelembaban Tanah

Pantau kelembaban tanah dari berbagai area secara real-time dengan jaringan sensor nirkabel.

Irigasi Otomatis

Sistem irigasi cerdas menggunakan fuzzy logic untuk mengontrol selenoid valve berdasarkan kebutuhan tanaman.

Deteksi Kematangan

Identifikasi tahap kematangan tanaman dengan computer vision dan machine learning.

Visualisasi Data

Pantau data historis dan tren melalui grafik interaktif yang memudahkan analisis.

Kontrol Manual

Kemampuan untuk mengganti ke kontrol manual saat diperlukan melalui web interface.

Penyimpanan Data

Semua data disimpan secara lokal untuk pencatatan dan analisis jangka panjang.

Cara Kerja Sistem

  1. Sensor kelembaban tanah pada node ESP32 membaca data.
  2. Data dikirim ke Raspberry Pi melalui WiFi.
  3. Raspberry Pi mengolah data dengan fuzzy logic.
  4. Perintah kontrol dikirim ke selenoid valve.
  5. Kamera mengambil gambar untuk deteksi kematangan.
  6. Semua data ditampilkan pada web interface.
